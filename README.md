# Shadani 3D Candy Demo

An interactive 3D candy experience, built as an unofficial concept demo for Shadani. This is not the official Shadani store. The Shadani name, logo and product details belong to their owner.

Pick a flavour and the can unscrews, the candy rises out and spins, and an info card appears. Close it and the candy drops back in and the lid screws shut.

Built with Three.js and GSAP. All models are generated in code.

## Run locally

Open `index.html` in a browser. It is a single self-contained file.

## Edit

```
npm install
npm run build
```

Source is in `src/`, and product details are in `src/data.js`. The build writes `index.html`.
